# CloudStream Web (experimental)\n\nA browser-based companion/reimplementation experiment for CloudStream. This project is not the official CloudStream project.\n\n## Current status\n\n- Next.js web application scaffold.\n- Server-side GitHub repository manifest fetcher with basic host allow-listing.\n- The browser cannot load Android `.cs3` packages as executable plugins. CloudStream extensions are Kotlin/Android-oriented; compatibility requires a JVM/Kotlin runtime plus Android API shims, or a web adapter per provider.\n- This initial scaffold does **not** execute `.cs3` extensions or promise compatibility.\n\n## Development\n\n- Node.js 20+\n- `npm install`\n- `npm run dev`\n\nDeploy on Vercel using the repository root and the Next.js preset.\n\n## Security\n\nOnly trusted repositories should be added. Future extension execution must be sandboxed and must never expose server secrets to provider code. Do not use this project to bypass access controls or copyright restrictions.\n\n## License\n\nCloudStream is a separate project. Review its GPL-3.0 license before copying or adapting its source.
